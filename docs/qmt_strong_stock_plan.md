# 基于 QMT 的集合竞价强势股捕捉思路（开盘第一时间买入）

## 1. 目标定义
- **核心目标**：在 9:25 集合竞价结束后，利用当日竞价数据 + 上一交易日量价结构，快速筛出“高确定性强势股”候选。
- **交易风格**：偏短线动量，强调“强中选强”，并控制开盘追高风险。

## 2. 数据准备（QMT 可获取）
- 当日集合竞价数据（9:25）：
  - 竞价成交额、竞价成交量
  - 竞价撮合价（开盘价）
  - 委买/委卖结构（若接口可用）
- 上一交易日日线数据：
  - 开高低收、成交量、成交额、换手率
  - 振幅、实体/影线结构
- 辅助数据：
  - 流通市值、所属板块、是否 ST、是否新股、是否停牌

## 3. 强势股指标（建议分层）

### 3.1 竞价强度指标（当日）
1. **竞价涨幅**：`open_ret = (open / prev_close - 1)`
   - 过滤建议：`1.5% ~ 6%`（过高容易高开低走，过低强度不足）
2. **竞价金额放大**：`auction_amt_ratio = auction_amt / avg_auction_amt_N`
   - N 可取 5~10 日同口径均值
3. **竞价量比**：`auction_vol_ratio = auction_vol / avg_auction_vol_N`
4. **竞价承接（若有盘口）**：`bid_imbalance = bid_amt / (bid_amt + ask_amt)`

### 3.2 前一日趋势与量价共振
1. **昨日涨幅适中偏强**：避免过度加速末端，建议 `2%~8%`
2. **昨日放量但不过热**：`vol_ratio_1d` 在 1.2~2.5 区间
3. **收盘位置**：`(close-low)/(high-low)` 越高越强（如 > 0.65）
4. **近 20 日位置**：接近突破位优于高位远离成本区

### 3.3 风险过滤
- 剔除：ST、次新（如上市 < 60 日）、一字板、长期停牌复牌首日
- 回避：前日天地板/大长上影放巨量、明显情绪退潮板块
- 流动性约束：如前一日成交额 > 3 亿

### 3.4 基本面过滤（仅做风险排雷，不做主要 alpha）
> 同意你的判断：在集合竞价短线场景里，基本面对收益解释力通常较弱。
> 建议把基本面定位为“**避雷器**”，而不是“收益增强器”。

1. **财务风险排除**：
   - 最近一期扣非净利润/经营现金流严重恶化的公司降权或剔除
   - 资产负债率异常高且持续上升的公司降权
2. **事件风险排除**：
   - 重大诉讼、立案调查、退市风险警示等直接剔除
3. **行业景气方向（可选）**：
   - 若你做纯技术流，可完全关闭这项，不影响主框架

实现建议：仅做布尔过滤 `fundamental_risk_flag`（0/1），触发即剔除；
不再把 `fundamental_score` 纳入主打分，避免稀释量价信号。

### 3.5 历史走势过滤（强烈建议）
短线策略里，历史走势比深度基本面更关键，建议加入：

1. **趋势状态**：
   - `ma5 > ma10 > ma20` 记为趋势加分
   - 跌破 `ma20` 的票直接降权
2. **突破有效性**：
   - 最近 20/60 日新高附近且伴随放量，优于“高位无量”
3. **波动与回撤结构**：
   - 近 10 日振幅过大（如 > 35%）且阴线占比高，视为不稳定
4. **历史开盘表现统计（可选）**：
   - 统计个股近 60 日“高开后 30 分钟收益”的胜率，作为先验权重

## 4. 评分体系（可直接用于程序）
定义综合分数：

`score = w1*Z(open_ret) + w2*Z(auction_amt_ratio) + w3*Z(auction_vol_ratio) + w4*Z(prev_day_close_pos) + w5*Z(prev_day_vol_ratio) + w6*Z(sector_strength) + w7*trend_score`

建议：
- 权重初值：`w1=0.18, w2=0.24, w3=0.20, w4=0.13, w5=0.10, w6=0.08, w7=0.07`
- 每日只取 TopN（如 5~10 只），降低分散噪音
- 若你偏纯量价短线，可继续下调 `w6`（板块因子）并上调 `w2/w3`

## 5. 交易执行建议（开盘第一时间）
1. **时间窗**：9:30:00 ~ 9:31:30 分批买入，避免单点冲击
2. **触发条件**：
   - 开盘后 1 分钟不破开盘价
   - 1 分钟成交额延续（不显著衰减）
3. **止损**：
   - 硬止损：`-2% ~ -3%`
   - 结构止损：跌破开盘价且分时放量下行
4. **止盈/减仓**：
   - `+4%~+6%` 分批减仓
   - 若强趋势可留底仓并抬升止损

## 6. Python 实现框架（QMT）
- `data_loader.py`：拉取竞价 + 历史日线 + 板块数据
- `features.py`：计算指标（竞价强度、昨日结构、风险标签）
- `scorer.py`：标准化、打分、排序
- `executor.py`：下单、风控、仓位管理
- `backtest_sim.py`：离线回放（近 6~12 个月）

## 7. 回测与参数校准建议
- 分阶段评估：
  - 信号质量（命中率、次日溢价）
  - 交易质量（滑点、成交率）
  - 组合质量（回撤、夏普、盈亏比）
- 参数调优顺序：
  1) 先调过滤条件（减少垃圾样本）
  2) 再调权重（提升排序质量）
  3) 最后调买卖规则（提升实盘可执行性）
- 防过拟合：滚动窗口 + 时间外检验（walk-forward）

## 8. 实盘落地注意事项
- 集合竞价数据的字段口径要先核对（不同接口略有差异）
- 开盘瞬时波动大，必须设置撤单/超时保护
- 记录每一笔信号与执行日志，便于复盘

## 9. 进阶增强方向
- 增加“板块联动分”（龙头/跟风识别）
- 加入盘口微结构特征（开盘前最后 30 秒委托变化）
- 用轻量模型（如 XGBoost）替代线性打分做二次排序



## 10. 补齐为“可实盘闭环”的关键模块

### 10.1 交易执行细则（避免信号好、执行差）
1. **下单方式**：
   - 默认限价单（参考开盘价上浮 `0.2%~0.5%`），超时未成交则撤单重报
2. **撤单与重试**：
   - 每笔订单超时（如 3~5 秒）自动撤单，最多重试 2 次
3. **滑点保护**：
   - 若实时成交价偏离信号价超过阈值（如 `0.8%`）则放弃追单
4. **成交回报监控**：
   - 成交率低于阈值（如 60%）时自动降仓或暂停策略

### 10.2 组合层风险控制（必须参数化）
1. **单票仓位**：不超过总资金 `10%~20%`
2. **总仓位上限**：开盘策略总仓位不超过 `50%~70%`
3. **行业集中度**：单行业持仓不超过组合 `30%`
4. **日内风控开关**：
   - 当日回撤超过 `-2%`：停止新开仓
   - 当日回撤超过 `-3%`：强制降杠杆/清理弱势仓位

### 10.3 监控与复盘（持续迭代核心）
- 记录字段：`signal_id, stock_code, signal_ts, factor_values, order_price, fill_price, fill_ratio, slippage_bps, pnl`
- 每日复盘输出：
  1) 信号命中率（开盘后 10/30/60 分钟）
  2) 成交质量（成交率、滑点、撤单率）
  3) 归因分析（是选股问题还是执行问题）

## 11. 如何用回测把胜率尽可能提高（重点）

> 目标不是“单次回测最高胜率”，而是“跨周期稳定高胜率 + 可执行”。

### 11.1 数据与样本切分（先防数据泄漏）
1. **样本分层**：按市场状态分层（上行/震荡/下行）分别评估
2. **时间切分**：
   - 训练集：历史前段
   - 验证集：中段（调参）
   - 测试集：最近一段（只评估，不调参）
3. **滚动检验**：walk-forward（例如每 3 个月重训参数，向后验证 1 个月）

### 11.2 先提纯样本，再优化模型
1. **先优化过滤规则**：
   - 把明显低质量样本先去掉（低流动性、情绪退潮、异常波动）
2. **再优化因子阈值**：
   - 例如对 `open_ret`、`auction_amt_ratio` 做网格搜索
3. **最后优化权重**：
   - 在稳定区间内选权重，不追求局部极值

### 11.3 胜率优化的实操指标体系
- 主指标：
  - `win_rate`（如开盘后 30 分钟正收益占比）
  - `profit_factor`（总盈利/总亏损）
- 约束指标：
  - 最大回撤 `max_drawdown`
  - 单日最差亏损分位数（如 P95）
  - 换手与成交率（保证可执行）

建议目标（可按风格调整）：
- `win_rate >= 55%`
- `profit_factor >= 1.2`
- `max_drawdown <= 12%`

### 11.4 参数搜索建议（避免过拟合）
1. **粗到细**：先大步长扫参数，再在优区间细扫
2. **稳健优先**：优先选择“在多窗口都不差”的参数组
3. **惩罚不稳定参数**：
   - 定义稳健分：`robust_score = mean(metric) - lambda * std(metric)`
4. **限制自由度**：
   - 单次迭代最多改 1~2 类参数，避免参数爆炸

### 11.5 交易成本与冲击成本建模（非常关键）
- 回测必须计入：手续费、印花税、滑点、未成交损失
- 对高开追单场景，建议分档滑点：
  - 流动性好：`5~10 bps`
  - 流动性一般：`10~25 bps`
  - 流动性差：`25+ bps`

### 11.6 从“高胜率”到“高收益质量”
- 胜率不是唯一目标，还要看盈亏比
- 可以通过以下方式提升收益质量：
  1) 弱势信号减仓（降低错误交易的损失）
  2) 强势延续信号留仓（放大利润）
  3) 分层止盈（提高利润分布右尾）

## 12. 推荐的落地节奏（两周版）
- **第 1-3 天**：完成数据对齐与特征计算，打通选股结果导出
- **第 4-6 天**：完成离线回测框架（含交易成本）
- **第 7-9 天**：完成参数网格 + walk-forward 验证
- **第 10-12 天**：完成模拟盘执行与监控告警
- **第 13-14 天**：复盘修正并准备小资金实盘
